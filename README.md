# Blackjack Ledger Online

เว็บ Blackjack ออนไลน์แบบห้องส่วนตัวตามกติกาคาสิโน รองรับผู้เล่นคนละ 1–3 มือเริ่มต้น แต่ละมือ Split ได้หนึ่งครั้ง (รวมสูงสุด 6 มือ), เดิมพัน 10–500 chip, ขอเปลี่ยนเจ้ามือ, อิโมจิ และ Dashboard สรุปยอดได้เสียแบบซ่อนได้

ทุกคนต้องคอนเฟิร์มก่อนเริ่มแต่ละขา, รองรับ Surrender เสียครึ่งเดิมพัน, เจ้​​ามือเลือก Shoe 1/2/4/6/8 สำรับ (เริ่มต้น 4), แสดงไพ่คงเหลือ และหลังจบขาจะกลับหน้าเตรียมตัวอัตโนมัติใน 10 วินาที

Shoe จะใช้ต่อเนื่องหลายขาโดยไม่สับใหม่ทุกครั้ง เมื่อไพ่เหลือ 25% (Cut Card) ระบบจะจบขาปัจจุบันก่อนและสับ Shoe ใหม่ก่อนขาถัดไป หน้าเตรียมตัวรอคอนเฟิร์ม 60 วินาที; เมื่อหมดเวลาเจ้ามือเริ่มได้และระบบแจกไพ่เฉพาะคนที่กดพร้อม

จำนวนสำรับเปลี่ยนได้เฉพาะก่อนเริ่ม Shoe แรก หรือในหน้าเตรียมตัวหลังถึง Cut Card ระหว่างที่ Shoe ยังใช้งานอยู่ปุ่มจำนวนสำรับจะถูกล็อก

เจ้ามือไม่ต้องกดพร้อม มีเพียงปุ่มเริ่มเกม ส่วนขาเล่นต้องกดคอนเฟิร์ม เจ้​​ามือเปิด–ปิดโหมดอัตโนมัติได้ เมื่อเปิด ระบบจะจั่วเองทุก 0.7 วินาทีขณะแต้มต่ำกว่า 17 และหยุดอัตโนมัติเมื่อแต้มตั้งแต่ 17

เมื่อเปิดโหมดเจ้ามืออัตโนมัติ จะเริ่มได้เฉพาะเมื่อขาเล่นทุกคนกดพร้อมครบ แม้เวลารอ 60 วินาทีหมดแล้วก็จะไม่ข้ามผู้เล่นที่ยังไม่พร้อม

เมื่อขาเล่นคนสุดท้ายกดพร้อมครบในโหมดเจ้ามืออัตโนมัติ ระบบจะรอ 0.7 วินาทีแล้วแจกไพ่เริ่มขาเองทันที เจ้​​ามือไม่ต้องกดปุ่มเริ่ม

## Render

- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Runtime: Node

การรีเฟรชหน้าเว็บจะกลับเข้าห้องเดิมอัตโนมัติ ตราบใดที่เซิร์ฟเวอร์ยังทำงานอยู่ ข้อมูลห้องเก็บในหน่วยความจำ จึงเริ่มใหม่เมื่อ Render restart หากต้องการเก็บถาวรให้เชื่อม PostgreSQL ในขั้นถัดไป
