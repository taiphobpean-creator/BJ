# Blackjack Ledger Online

เว็บ Blackjack ออนไลน์แบบห้องส่วนตัว รองรับการเลือกเจ้ามือ เดิมพัน 10–500 chip เล่นหลายขา และ Dashboard สรุปยอดได้เสีย

## StackBlitz

อัปโหลดโปรเจกต์หรือเปิด Repository ใน StackBlitz แล้วรัน `npm install` และ `npm run dev`

## Render

- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Runtime: Node

ข้อมูลห้องเก็บในหน่วยความจำของเซิร์ฟเวอร์ จึงเริ่มใหม่เมื่อ Render restart เหมาะสำหรับห้องเกมชั่วคราว
